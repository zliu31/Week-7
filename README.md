# Week 7 Project - GitHub Pages Site

This repository contains a simple website deployed using GitHub Pages.

## Viewing the Website

Once GitHub Pages is enabled, your website will be accessible at:
```
https://[username].github.io/Week-7
```

## How to Enable GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings** (top navigation)
3. Scroll down to the **Pages** section in the left sidebar
4. Under **Source**, select the branch you want to deploy from (e.g., `claude/github-public-page-view-011CUcXM1knK827Fa9r9iPnR` or merge to main first)
5. Select the root folder `/` as the source directory
6. Click **Save**
7. Wait a few minutes for GitHub to build and deploy your site
8. Your site URL will appear at the top of the Pages settings

- Changes pushed to the selected branch will automatically update the live site
